Make sure you have [Node.js](https://nodejs.org/) version 18.0 or above installed.

## Install Docusaurus

<Tabs groupId="package-manager">
  <TabItem value="npm" default>
    ```bash
    npm init docusaurus@latest my-website classic
    ```
  </TabItem>

  <TabItem value="yarn">
    ```bash
    yarn create docusaurus my-website classic
    ```
  </TabItem>

  <TabItem value="pnpm">
    ```bash
    pnpm create docusaurus my-website classic
    ```
  </TabItem>
</Tabs>

## Start the development server

<Tabs groupId="package-manager">
  <TabItem value="npm" default>
    ```bash
    cd my-website
    npm run start
    ```
  </TabItem>

  <TabItem value="yarn">
    ```bash
    cd my-website
    yarn start
    ```
  </TabItem>

  <TabItem value="pnpm">
    ```bash
    cd my-website
    pnpm start
    ```
  </TabItem>
</Tabs>

Your site will be available at `http://localhost:3000`.

## Build for production
